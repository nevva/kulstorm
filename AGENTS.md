# Project instructions

- This project is an experiment. Favor small, simple changes and quick iteration. Avoid unnecessary architecture, dependencies, and production process.
- For now, the app is hosted on GitHub Pages, serving static files from `docs/` with no build step. Keep changes compatible with that setup. Do not introduce a required backend, build pipeline, or hosting migration unless the user asks.
- `node dev.js` is the local development server, not a production backend.
- Keep verification proportional to the change. Use focused checks; documentation-only changes do not need runtime tests.
- Speak to the user in short, simple caveman-style replies. Keep technical details, commands, and file paths clear and accurate.
